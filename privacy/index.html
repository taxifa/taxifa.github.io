Účinnost: ode dne zveřejnění webu na ai.taxifa.cz

1. Rozsah a účel

Agent007 je neveřejný osobní AI asistent provozovaný pro jednoho uživatele. Není nabízen veřejnosti, neumožňuje registraci dalších uživatelů a neposkytuje veřejný přístup k účtu Google, interním službám ani datům uživatele.

Tyto zásady popisují, jak Agent007 zachází s údaji získanými prostřednictvím Google API. Veřejný web ai.taxifa.cz sám žádná osobní data neshromažďuje.

2. Google data, ke kterým může Agent007 přistupovat

Gmail

Metadata zpráv, odesílatelé a příjemci, předměty, úryvky a textový obsah zpráv, identifikátory zpráv a vláken a informace o štítcích či stavu zprávy.

Google Calendar

Údaje o událostech v primárním kalendáři, zejména názvy, termíny a časy. Agent007 může na pokyn uživatele vytvořit novou událost.

Google Sheets

Metadata a hodnoty v tabulkách, které uživatel určí. Na základě potvrzeného požadavku může Agent007 tabulku vytvořit, zapsat nebo přidat hodnoty a přidat nový list.

Agent007 používá pouze oprávnění potřebná pro tyto funkce. Nové oprávnění nebude přidáno bez nového výslovného souhlasu uživatele.

3. Jak jsou Google data používána

Data jsou používána pouze k provedení funkcí vyžádaných uživatelem, například k vyhledání a shrnutí e-mailů, přípravě návrhu odpovědi, sestavení přehledu, zobrazení kalendáře nebo práci s určenou tabulkou.

Operace měnící Gmail nebo Google Sheets vyžadují výslovné potvrzení uživatele. Vytvoření kalendářní události se provádí pouze na základě výslovného požadavku uživatele.

Google data nejsou prodávána, používána pro reklamu, reklamní profilování, hodnocení úvěruschopnosti ani zpřístupňována třetím stranám pro jejich vlastní marketingové účely.

4. Technické zpracování a poskytovatelé

Podle požadované úlohy mohou být nezbytné části dat technicky zpracovány těmito službami:

  • Google API pro přístup k Gmailu, Google Calendar a Google Sheets;
  • soukromý server, na kterém běží Agent007 a jeho automatizace;
  • nakonfigurovaný poskytovatel AI modelu, v současnosti OpenAI, pokud je zpracování obsahu nezbytné k vytvoření uživatelem požadovaného shrnutí, návrhu nebo odpovědi;
  • Telegram, pokud uživatel zadá požadavek nebo si nechá doručit výsledek prostřednictvím této služby.

Tito poskytovatelé jsou využíváni pouze k zajištění funkce požadované uživatelem. Agent007 nepoužívá Google data k trénování vlastního obecného AI modelu.

5. Ukládání a zabezpečení

OAuth pověření jsou uložena neveřejně na soukromém serveru v souborech s omezenými oprávněními operačního systému. Nejsou součástí veřejného webu ani veřejného zdrojového repozitáře.

Obsah načtený z Google služeb může být po dobu zpracování součástí konverzačního kontextu asistenta. Odvozené souhrny, strukturované údaje a provozní historie mohou být uloženy v historii asistenta, lokálních pracovních datech nebo v uživatelem určené tabulce Google Sheets. Provozní monitoring uchovává zejména technický stav, časy kontrol a chybové kódy; nemá za účel ukládat obsah Gmailu.

Přenos ke Google API a veřejnému webu probíhá přes HTTPS. Veřejný web není propojen s interními službami a nezpřístupňuje dashboard, agenty, API, protokoly ani uživatelská data.

6. Doba uchování

OAuth pověření se uchovávají do jejich nahrazení, odvolání nebo odstranění. Konverzační historie, odvozené souhrny, strukturované pracovní údaje a provozní záznamy mohou být uchovávány po dobu potřebnou pro osobní používání, návaznost úloh, bezpečnost, diagnostiku a zálohování. V současnosti není u všech těchto lokálních dat nastavena jednotná automatická doba výmazu.

Data uložená přímo v Gmailu, Google Calendar nebo Google Sheets se řídí nastavením a dobou uchování účtu Google.

7. Odvolání přístupu a odstranění dat

Uživatel může kdykoli odvolat přístup aplikace ke Google účtu. Tím se zabrání dalšímu přístupu, ale automaticky se neodstraní dříve vytvořené lokální souhrny nebo provozní historie.

Požadavek na odstranění dat může vlastník účtu uplatnit u provozovatele Agent007. Lze odstranit lokálně uložená OAuth pověření, konverzační historii a odvozená pracovní data v rozsahu, v jakém nejsou potřebná pro bezpečnostní záznamy nebo zákonné povinnosti. Pro kontakt bez zveřejnění osobních kontaktních údajů je zatím určen veřejný profil GitHub taxifa; citlivá data se nemají vkládat do veřejných příspěvků.

8. Cookies, analytika a veřejný web

Web ai.taxifa.cz nepoužívá cookies, analytické nástroje, reklamní systémy, trackery, formuláře ani klientský JavaScript. Statické soubory poskytuje GitHub Pages, jehož infrastruktura může z bezpečnostních a provozních důvodů zpracovávat standardní síťové údaje, například IP adresu a čas požadavku.

9. Google API Services User Data Policy

Používání informací získaných z Google API se řídí Google API Services User Data Policy, včetně požadavků Limited Use.

10. Změny těchto zásad

Zásady budou aktualizovány, pokud se podstatně změní používané Google služby, účel zpracování, poskytovatelé nebo způsob uchování dat. Aktuální znění bude vždy zveřejněno na této adrese.
